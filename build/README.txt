轻算计算器 1.0.0
==============================

一个原生 Windows 计算器，标准型 / 科学型双模式，深色界面。

启动方式
--------
开始菜单 → 轻算计算器
（安装时勾选“创建桌面快捷方式”则桌面上也有图标）

功能
----
标准型：
  四则运算 + - × ÷、百分比 %、正负号 ±、清除 C / CE、退格 ⌫
  倒数 1/x、平方 x²、开方 √x
  内存 MS / MR / M+ / M- / MC
  连续运算与连按等号重复上次运算

科学型（标题栏右侧“科学”按钮，或 Alt+2）：
  sin cos tan、asin acos atan（DEG / RAD 可切换）
  log ln、10^x、e^x、x^y、mod
  x³、³√x、n!、|x|、floor、ceil
  常量 π、e

键盘
----
  0-9 、 .        输入数字
  + - * /         四则运算
  Enter / =       计算结果
  Shift+5         百分比
  Backspace       退格
  Delete          清除当前项 (CE)
  Esc             全部清除 (C)
  F9              正负号
  R               倒数 (1/x)
  Q               平方
  Alt+1 / Alt+2   标准型 / 科学型
  Shift+1         快捷键说明

系统要求
--------
  Windows 7 SP1 及以上（Windows 10 / 11 体验最佳）
  需要 .NET Framework 4.6+（Windows 10/11 已内置）

卸载
----
  设置 → 应用 → 轻算计算器 → 卸载
  或开始菜单 → 卸载 轻算计算器
